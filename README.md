# YAHYA | Boiling Point Lab

## Run on Windows / VS Code
Open this folder in VS Code, then open Terminal > New Terminal and run:

```powershell
py -m pip install -r requirements.txt
py -m streamlit run app.py
```

Streamlit normally opens http://localhost:8501 in your browser.

The application uses the Antoine equation with pressure in mmHg and temperature in °C. Verify constants and validity ranges against your course references before final submission.
